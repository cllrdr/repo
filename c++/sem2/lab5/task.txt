Нужно реализовать на c++ механизм передачи сообщения типа producer -> consumer
1. producer генерирует сообщение (например пользовательским вводом), consumer читает это сообщение и выводит на экран или пишет в файл в потоковом режиме
2. класс/объект/библиотека должны предоставлять возможность писать в этот канал и читать из него в многопоточном режиме. 
3. канал должен быть ограничен максимальным размером
4. предоставить интерфейс взаимодействия через самописный класс итератора (примерно через финкции iter, next)
5. предоставить возможность реализации на кольцевом буфере в памяти

Тип сообщений: срока
Многопоточность: thread-safe не нужен, producer и consumer только один, политика блокировок - mutex
Ограничение размера канала: Блокировка producer до освобождения места
Интерфейс итератора: потокобезопасность не важна, лучше сделать проще, обратный итератор не нужен
Кольцевой буфер: гарантия атомарности не требуется, буфер фиксированного размера (если проще динамический, то динамический)
Дополнительный требования: не требуются
Дополнительные бибилотеки:  механизм очереди должен быть самописным (без библиотеки queue)
Тестирование: юнит тесты не нужны, нужен main.cpp для запуска простого тестирования функциональности
